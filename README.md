# Glaucoma Visual Field Visualizer

A simple Python OpenGL project that simulates glaucoma-related vision loss and visualizes the difference between normal and tunnel vision.

### Features

* Normal & glaucoma vision simulation
* Left/Right eye selection
* Interactive visual field test
* Cohen-Sutherland line clipping
* 2D OpenGL graphics and mouse/keyboard interaction

### Run

```bash
pip install PyOpenGL PyOpenGL_accelerate
python main.py
```

> This project is for educational purposes and is not a medical diagnostic tool.
